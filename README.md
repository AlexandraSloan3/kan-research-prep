# KAN Research Preparation

Prerequisite study for [KAN research](https://github.com/AlexandraSloan3/kan-research) — mathematical foundations, notes from the primary literature, and implementation practice, worked through before and alongside the main project.

- MIT 18.06 — Linear Algebra
- *Dive into Deep Learning* (Zhang, Lipton, Li & Smola) — the online resource for a Stanford course
- Thomas' Calculus / MIT 18.01–18.02
- MIT 6.041/18.05 — Probability
